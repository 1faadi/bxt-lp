# Testimonials Specification

## Overview
- Target: `Testimonials.tsx`; static/reveal.
## DOM Structure
Eyebrow > three quote columns > name/title.
## Computed Styles
Alternate warm background; 120px padding; quote 24px/1.35; 1px vertical separators.
## States & Behaviors
Staggered reveal; no rating UI.
## Assets
Small CSS initials, no portraits.
## Text Content
Three original client quotes for Atlas Freight, Meridian Clinics, and Forma Capital.
## Responsive Behavior
Single column on mobile with horizontal separators.
