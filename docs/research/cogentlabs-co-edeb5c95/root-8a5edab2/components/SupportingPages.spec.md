# Supporting Pages Specification

## Overview
- Targets: `/services`, `/case-studies`, `/case-studies/[slug]`, `/blogs`, `/blogs/[slug]`, `/about-us`; static editorial pages with shared header/footer.
## DOM Structure
Header > page hero > route-specific large rows/grids > closing CTA > footer.
## Computed Styles
Warm canvas, 1280px shell, 176px hero top padding, 72px display title, 144px major section padding, 1px separators, no shadows.
## States & Behaviors
Native links, section reveals, 4px arrow hover and 1.02 project visual hover.
## Assets
Original CSS-built product/editorial visuals.
## Text Content
Original BXTrack copy following the supplied services, case studies, insights, and about outlines.
## Responsive Behavior
12-col desktop, 2-col tablet, single-column mobile; metrics remain 2×2.
