# Page Topology

1. Fixed SiteHeader — scroll-driven styling; click-driven mobile menu.
2. Hero — static editorial copy plus abstract product preview.
3. ResultsProof — editorial statement and three BXTrack proof metrics.
4. Services — five numbered editorial rows with hover motion.
5. SelectedWork — one full-width feature and two half-width case studies.
6. Impact — dark 2×2 metrics field.
7. Process — four horizontally connected steps.
8. Testimonials — three editorial columns.
9. ClosingCta — minimal near-black conversion section.
10. SiteFooter — four link groups and legal row.

Desktop uses a 12-column, 1280px container. Tablet collapses complex grids to two columns. Mobile uses one column except metrics remain 2×2. Supporting routes reuse the same header, footer, typography, and editorial sections.
