# Behaviors

- Reference header is fixed and remains dark while scrolling.
- Hero and article are static flow content; the reference uses no click-to-switch content.
- Case-study cards link to individual routes and lift slightly on hover.
- Detail page desktop hero uses a two-column layout; the source heading is 64px / 70.4px, weight 600, with -2.24px tracking. Section headings are 32px / 38.4px, weight 600.
- At mobile, navigation becomes horizontally scrollable and the two-column compositions stack.
