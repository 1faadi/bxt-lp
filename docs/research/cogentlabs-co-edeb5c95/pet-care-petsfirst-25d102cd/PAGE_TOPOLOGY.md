# Page topology

1. Fixed dark BXTrack navigation.
2. Dark, subtle-grid hero: all-case-studies link, category, project heading, supporting line, three result cards, product illustration.
3. Cream project body: narrow sticky-style metadata rail beside long-form case-study sections.
4. Alternating challenge, solution, implementation, workflow, and results sections separated by rules.
5. Dark result recap and a closing inquiry panel, followed by the existing BXTrack footer.

The page is static apart from normal link/card hover transitions and responsive reflow. At desktop the hero and article use two columns; at mobile all content stacks and the meta rail becomes a two-column information grid.
